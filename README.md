# ⏪ PROJECT REWIND

**Make mistakes. Learn safely. Earn rewards.**

Many people avoid digital services, or fall for scams, because they have no safe place to practise. PROJECT REWIND is that place.

## Live Demo

https://project-rewind-ten.vercel.app/

## Features

- **UPI Practice:** practise digital payments without risking real money
- **Treasure Hunt:** learn by completing fun challenges
- **REWIND RESCUE:** go back and fix mistakes safely
- **Practice Before It Happens:** rehearse scam situations before they happen to you
- **My Journey:** track your progress and rewards
- **Accessibility:** Large Text, High Contrast, Read Aloud, and Hindi language support

## Tech Stack

- HTML, CSS and JavaScript (single-file website)
- Hosted on Vercel

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation or dependencies needed.
